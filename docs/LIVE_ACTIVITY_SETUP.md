# 实时活动与监控启用

安装包含 ActivityKit / WidgetKit 扩展的新版 App 后，系统实时活动仍需用户主动启动，后台更新还需独立监控服务和可用 APNs 身份。仅连接 CPA、添加桌面 Widget 或允许普通通知，不会自动建立监控活动。

## 先准备独立服务

按 [监控部署](MONITOR_DEPLOYMENT.md) 配置可信 HTTPS、CPA 来源、明确账号白名单、独立监控访问令牌（技术文档称 Bridge Token）和加密状态。服务中的 `sources[].id` 为授权来源标识，连接验证后会由客户端通过 `GET /v1/capabilities` 拉取并在「授权来源」选择器中展示。

Development 包必须与服务端 Sandbox APNs 环境匹配；分发包应核对其实际签名环境。`apns.bundle_id` 使用主 App 的 `icu.nahida.cpaquota`，不是扩展的 `.activity` 标识，服务自行添加 `.push-type.liveactivity`。私钥只在服务端，CPA 管理密钥、CPA 客户端 API Key、监控访问令牌和活动 push token 不能相互替代。

`dry_run=true` 仅禁止 APNs，有有效活动时仍可能采集 CPA；它不是完全离线开关。服务合并到 main 或构建成功不会自动部署、获取授权或生成真实设备 token。

## 手机设置与开始监控

1. **允许实时活动权限**：在系统设置中找到 App 的实时活动权限并允许；返回 App 后会重新读取系统授权。
2. **验证并连接监控服务**：进入「连接管理 › 监控与活动」，打开「连接监控服务」，填写部署方提供的监控服务 HTTPS 地址和独立监控访问令牌并点击验证连接。客户端会立即请求 `GET /v1/capabilities` 核对令牌授权、拉取允许的来源/账号清单与容量状态；验证失败不会覆盖既有可用连接。
3. **选择授权来源、账号与时长**：授权验证通过后，在「授权来源」选择器中选取来源（若服务仅授权 1 个来源，客户端会自动选中）；进入「监控账号」从「监控服务已授权的账号」（来自服务端令牌授权清单，不依赖本地 CPA 账号列表）选择 1 至 5 个账号，并选择 1、4 或 8 小时监控时长。
4. **开始监控**：点击「开始监控」，客户端会再次核对授权与容量，随后请求系统创建活动并自动取得 push token。无需手工复制 token，也不要使用虚构值测试推送。首次采集前可以点一次「请求更新读数」，再返回桌面或锁屏观察真实显示。

## 开始监控不可点击

| 条件 | 检查方式 |
| --- | --- |
| 监控连接未配置 | 先在「连接监控服务」完成地址、令牌填写并连接 |
| 尚未通过授权验证（`!hasVerifiedAuthorization`） | 点击验证/重新验证监控服务，确认 `GET /v1/capabilities` 返回有效授权清单（404 表示服务端未支持能力接口需升级） |
| 服务端容量已满（`capacity.canCreateSession != true`） | 查看容量提示与诊断中的计数/上限；v1 历史意图与取消墓碑不自动回收 |
| 未选择授权来源 | 在「授权来源」选择器中选定来源（单来源时自动填入） |
| 未选监控账号 | 「监控账号」须从服务端授权清单选择 1 至 5 个，不能为 0 |
| 系统实时活动未允许 | 根据页面提示打开系统设置开启实时活动权限后返回 |
| 当前平台不支持 | 系统活动入口要求受支持的 Apple 移动平台；Linux 模型测试不能证明它可用 |
| 仍有连接、授权核验、会话、token 轮换或缓存请求进行中 | 页面可能显示正在连接或正在处理；记录该状态，不通过删除恢复记录或重装绕过 |

按钮颜色不是可点击状态的可靠证明。以上是源码中的启用条件（见 `Sources/CPAQuotaUI/MonitoringTabView.swift`），不是对任何一台手机故障根因的断言；条件均满足仍不能点击时，需要实际界面或运行证据。截图前遮挡令牌、邮箱及其他私人信息，不能用健康检查通过替代手机状态验证。

## 验收和停止

健康 200、受理 202、会话 active、APNs sent/ended 与设备实际展示是不同状态。首次没有缓存时授权 quota GET 返回 404 可以是正常结果；同来源约 600 秒采集是服务目标，不保证设备每 10 分钟更新。系统控制紧凑、最小、展开和锁屏呈现；当前不承诺后台自动轮播账号。

「仅停止本机实时活动显示」不会取消远端采集。「停止监控」需要服务端确认持久取消；超时或未知 404 都不能当作已经停止。不要删除加密状态、取消墓碑或清空 Keychain 来掩盖未确认结果。

当前仓库没有普通额度告警横幅/声音通知链路，也不通过服务端远程创建活动。真实额度、后台更新、设备离线、强退、锁屏隐私和 APNs 送达须用授权的真实活动逐项验收。
