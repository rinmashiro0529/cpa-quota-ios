# 文案编辑准则

界面当前使用中文。页面名称使用「额度总览」「CAP 用量」「监控与活动」「账号诊断」「连接管理」；日常用户提示使用「额度」，协议、类型与字段名称保持原样。

主动查询称「最近查询」，保留的旧数据称「上次读数」；时间未知、过期与读取失败分别说明，不能将未知写成零或将旧结果写成新成功。

CPA 管理密钥用于 CPA 管理接口；监控访问令牌用于独立监控服务。首次提及时说明区别，技术文档保留 Bridge Token、Keychain 及准确协议字段。

中文与英文缩写、数字与单位之间留空格，例如「CAP 用量」「近 30 分钟」「600 秒」「4 MiB」；中文句子使用中文标点，代码、命令与协议值保留原格式。

普通提示说明现状、影响和下一步；统计口径与操作差异放在帮助中，状态码、原始枚举和协议细节保留在高级诊断或技术指南。不得省略认证熔断、数据完整性、刷新受理与设备送达、本机关闭与远端停止等必要区别。

提交前在仓库根目录执行公开用语检查；该检查只处理 Git 跟踪的 Markdown，不替代人工审阅。

```powershell
python -I -B ci/validate_public_copy.py --root .
```
