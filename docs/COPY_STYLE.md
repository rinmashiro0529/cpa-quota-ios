# 文案编辑准则

界面当前使用中文。页面名称使用「额度总览」「CAP 用量」「AI 对话」「账号诊断」「连接管理」；「监控与活动」是「连接管理」内的页面，不是独立标签页。日常用户提示与小组件统一使用「额度」（不用「配额」），协议、类型与字段名称保持原样。

主动查询称「最近查询」，保留的旧数据称「上次读数」（小组件与实时活动中已观察数据亦沿用「最近查询 / 上次读数」体系）；时间未知、过期与读取失败分别说明，不能将未知写成零或将旧结果写成新成功。

## 凭据与概念统一称谓

首次提及时说明各类凭据的用途与隔离边界，避免混用：

| 概念 | 用户可见层统一称谓 | 技术文档可保留术语 | 避免混用 |
| --- | --- | --- | --- |
| 管理接口凭据 | CPA 管理密钥 | Management Key / Bearer Key | 泛称“密钥” |
| AI 对话推理凭据 | CPA 客户端 API Key | Client API Key | 「普通推理 API Key」、裸用「Key」 |
| 独立监控服务凭据 | 监控访问令牌（入口称「监控服务」） | Bridge Token / `MonitorBridgeToken` | 在用户报错/提示中出现「桥接」「原桥接」 |
| 联网搜索凭据 | 第三方搜索 API Key / 搜索 Key | `search-key|<provider>` | 与 CPA 客户端 API Key 混淆 |
| 模型思考强度与过程 | 「思考等级」「思考过程」 | `reasoning_effort` / `reasoningTokens` | 将 inference（推理请求）与 reasoning（思考）混写 |

## 排版与信息分层

中文与英文缩写、数字与单位之间留空格，例如「CAP 用量」「近 30 分钟」「600 秒」「4 MiB」「Swift 6.4.1」「iOS 17.0」；中文句子使用中文标点，代码、命令与协议值保留原格式。

普通提示说明现状、影响和下一步；统计口径与操作差异放在帮助中，状态码、原始枚举和协议细节保留在高级诊断或技术指南，不在 README 功能清单堆砌底层协议路径。不得省略认证熔断、数据完整性、刷新受理与设备送达、本机关闭与远端停止，以及 AI 对话消耗额度与联网搜索外发数据等必要区别。
